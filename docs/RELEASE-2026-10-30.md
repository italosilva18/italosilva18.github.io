## Dependências e limites

A instalação foi refeita com `npm ci`. Foram aplicadas correções patch/minor compatíveis e um override restrito de `postcss-selector-parser` 6.1.5 sob `@tailwindcss/typography`, cujo pin transitivo mantinha a versão vulnerável. Não foi usado `audit fix --force`.

O servidor Vite usa `127.0.0.1` por padrão. Não expor Vite/Vitest à rede nem usar esses servidores como runtime público; publicar apenas os artefatos estáticos. O audit residual é dívida registrada, não um audit limpo. Sem migração major de Vite, Vitest, React Router ou Zod nesta release.

`npm audit` final: **5 pacotes sinalizados, 3 moderate / 2 high / 0 critical**, contra 23 inicialmente. Restam `esbuild`, `vite`, `react-router`, `react-router-dom` e `zod`; correções completas indicadas pelo audit exigem Vite 8, Router 7 e Zod 4. Router foi atualizado de 6.30.1 para 6.30.6, dentro da faixa compatível, corrigindo os avisos high que tinham patch. O código usa BrowserRouter/Routes para home/404, sem loaders, SSR, redirects ou destinos de navegação vindos de input; não há consumo de Zod nas páginas atuais. O runtime Pages serve artefatos estáticos. Isso delimita o risco e não substitui migrações futuras. Fontes: [Vite](https://github.com/vitejs/vite/security/advisories/GHSA-rq7h-c2jc-7f22), [Router](https://github.com/remix-run/react-router/security/advisories/GHSA-wrjc-x8rr-h8h6), [Zod registrado no audit](https://github.com/advisories/GHSA-mrhx-c7xc-m3w5).
